For a model that reasons before answering, a small reply limit runs out before the answer starts. Raise the limit, or try these to shorten or switch off the reasoning. What works depends on the model: use "Test model" and "Try the model on this page" to see.

Settings are saved in cache/ui-settings.json, which is not committed and is readable only by you; that includes the API key, which is never sent back to this page. Changing the model makes every card "need extracting" again, since candidates are kept per model.
